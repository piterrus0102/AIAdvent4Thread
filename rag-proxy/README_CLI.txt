ИСПОЛЬЗОВАНИЕ CLI КЛИЕНТА
==========================

Терминал 1 (Сервер):
-------------------
cd mcp-proxy && npm start

Команды в консоли сервера:
  rag on      - Включить RAG режим
  rag off     - Выключить RAG режим
  rag         - Показать режим
  status      - Полный статус


Терминал 2 (CLI клиент):
------------------------
node rag-proxy/chat-cli.js

Команды в клиенте:
  /status     - Показать режим сервера
  /clear      - Очистить экран
  /help       - Справка
  /exit       - Выход

Просто вводите вопросы и получайте ответы!
CLI автоматически определяет режим сервера.
