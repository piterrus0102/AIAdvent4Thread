# Стартовый интерфейс

При открытии проекта в Android Studio первым делом мы видим стартовый интерфейс среды разработки.

![Общий вид интерфейса Android Studio](/images/android-studio/part_1_lesson_1_image_1.png)

Он состоит из двух ключевых элементов:
- **Центральная область** — текстовый редактор;
- **Боковые панели** с множеством иконок, расположенных по периметру окна.

Дополнительные инструменты можно найти, нажав на иконку с тремя точками, расположенную в верхней части левой боковой панели. Каждая из иконок отвечает за конкретную группу функций — их мы подробно разберём в следующих разделах.

## Структура панелей

По умолчанию иконки и функциональные панели разделены на три смысловые зоны:

### 1. Верхняя часть левой боковой панели
Отвечает за навигацию и структуру проекта.

Она включает две подгруппы:
- элементы, отвечающие за дерево проекта и менеджер ресурсов;
- элементы, связанные с вариантами сборки и структурой текущего файла (открытого в центральной части).

### 2. Нижняя часть левой боковой панели
Содержит инструменты, связанные с выполнением, отладкой и выводом. Здесь отображаются результаты сборки, логи, консоль, состояние системы контроля версий и другие окна процессов.

### 3. Правая боковая панель
Включает вспомогательные визуальные инструменты, ассистенты и средства взаимодействия с устройством (физическим или эмулированным).

## Поведение панелей

В каждой из этих зон в один момент времени может быть активна только одна панель. Если фокус находится в конкретной зоне, активная иконка подсвечивается синим цветом. Иконки неактивных зон отображаются серым.

![Демонстрация активных и неактивных панелей](/images/android-studio/part_1_lesson_1_image_2.png)

## Центральная область

В центральной области (редактор кода), при отсутствии открытых файлов, отображается краткий список горячих клавиш и напоминание о возможности открыть файл через drag'n'drop.
