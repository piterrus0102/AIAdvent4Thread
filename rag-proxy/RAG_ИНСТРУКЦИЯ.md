# 🚀 RAG-СИСТЕМА - Инструкция по использованию

## ✅ Что реализовано

Полнофункциональная **RAG (Retrieval-Augmented Generation)** система для курса "Android Studio для непрограммистов":

### Компоненты:
1. **Векторизация** - `mxbai-embed-large` (Ollama)
2. **LLM генерация** - `Qwen2.5-7B-Instruct` (HuggingFace)
3. **Векторный поиск** - Косинусное сходство
4. **Умное чанкование** - ~1500 символов на чанк

---

## 📋 Требования

### 1. Ollama (для векторизации)
```bash
# Установка (если еще нет)
brew install ollama

# Скачивание модели для векторизации
ollama pull mxbai-embed-large

# Проверка
ollama list
```

### 2. HuggingFace API токен
Добавьте в `mcp-proxy/.env`:
```bash
HUGGINGFACE_API_KEY=ваш_токен_здесь
```

Получить токен: https://huggingface.co/settings/tokens

## 🔍 Примеры работы

### Запрос 1: "power save mode"
**Ответ:**
> "Power Save Mode" в Android Studio позволяет временно отключить ряд функций, таких как фоновая индексация кода, подсветка синтаксиса, автокомплит и анализатор кода, чтобы снизить нагрузку на CPU и RAM.

**Релевантность:** 54.5%

---

**Ответ:**
> Инвалидация кэшей в Android Studio используется для очистки кэшей IDE и перезапуска среды разработки, что помогает устранить сбои и нестабильное поведение.

**Релевантность:** 77.8%

---

### Запрос 3: "эмулятор"
**Ответ:**
> Эмулятор в Android Studio позволяет тестировать приложения на виртуальных устройствах различных версий Android без необходимости физических устройств.

**Релевантность:** 63.8%

## 🔑 Ключевые концепции

### Векторизатор ≠ LLM

**Две разные модели работают вместе:**

| Компонент | Модель | Задача |
|-----------|--------|--------|
| **Векторизатор** | `mxbai-embed-large` | Текст → вектор для поиска |
| **LLM** | `Qwen2.5-7B-Instruct` | Генерация ответа |

### Чанкование

- Длинные статьи разбиваются на чанки ~1500 символов
- Каждый чанк сохраняет `parent_id` (ID оригинальной статьи)
- При генерации ответа используется **вся статья** (все её чанки)

### Векторный поиск

- Вопрос векторизуется той же моделью
- Ищутся похожие векторы через косинусное сходство
- Топ-3 релевантные статьи передаются в LLM

## 🎓 Дополнительная информация

### Что такое RAG?

**RAG (Retrieval-Augmented Generation)** - архитектура, которая:
1. Находит релевантные документы (Retrieval)
2. Дополняет запрос найденным контекстом (Augmented)
3. Генерирует ответ на основе контекста (Generation)

### Преимущества RAG:

✅ LLM отвечает на основе **ваших данных**, а не только тренировочных  
✅ Всегда **актуальная информация** (обновляете документы → обновляете индекс)  
✅ **Точные ответы** с указанием источника  
✅ Нет **галлюцинаций** - LLM не придумывает факты
