# 🚀 Быстрый старт - MCP Integration

## Что делает эта интеграция?

Добавляет в Android приложение возможность подключаться к **реальным MCP серверам** и использовать их инструменты.

**MCP (Model Context Protocol)** - это протокол от Anthropic для расширения возможностей AI с помощью различных инструментов.

## Результат работы

✅ **Новый экран "MCP Connection"** на стартовом экране  
✅ **Подключение к реальному filesystem MCP серверу**  
✅ **Отображение 14 инструментов** для работы с файлами  

## Запуск за 3 шага

### Шаг 1: Запустите прокси-сервер

```bash
cd mcp-proxy
npm install
npm start
```

Вы увидите:
```
[MCP Proxy] Server is running on http://0.0.0.0:3000
```

**Оставьте этот терминал открытым!**

### Шаг 2: Запустите Android приложение

В новом терминале:

```bash
cd ..
./gradlew installDebug
```

Или используйте Android Studio: **Run → Run 'app'**

### Шаг 3: Протестируйте функционал

1. Откройте приложение на эмуляторе/устройстве
2. На стартовом экране найдите карточку **"🔌 MCP Connection"**
3. Нажмите на неё
4. На экране MCP нажмите кнопку **"Подключиться"**
5. После подключения увидите список из 14 инструментов

## Что вы увидите?

После подключения отобразятся инструменты:

```
✓ read_file - Чтение содержимого файла
✓ write_file - Запись в файл
✓ list_directory - Список файлов в директории
✓ create_directory - Создание директории
✓ move_file - Перемещение файла
✓ search_files - Поиск файлов
... и еще 8 инструментов
```

## Проверка работы прокси (опционально)

Протестируйте прокси-сервер перед запуском приложения:

```bash
cd mcp-proxy
./test-proxy.sh
```

Или вручную:

```bash
# 1. Health check
curl http://localhost:3000/health

# 2. Подключение к MCP
curl -X POST http://localhost:3000/connect \
  -H "Content-Type: application/json" \
  -d '{"serverName": "filesystem"}'

# 3. Получение инструментов
curl http://localhost:3000/tools
```

## Важные замечания

### Для Android эмулятора:
- ✅ URL по умолчанию: `http://10.0.2.2:3000`
- ℹ️ `10.0.2.2` - это специальный IP для доступа к localhost хост-машины

### Для реального устройства:
- Замените URL на IP вашего компьютера: `http://192.168.X.X:3000`
- Устройство и компьютер должны быть в одной Wi-Fi сети

## Troubleshooting

### Ошибка "Не удалось подключиться"

**Решение:**
1. Убедитесь, что прокси-сервер запущен: `curl http://localhost:3000/health`
2. Проверьте URL в приложении (должен быть `http://10.0.2.2:3000` для эмулятора)
3. Перезапустите прокси-сервер

### Прокси-сервер не запускается

**Решение:**
1. Убедитесь, что установлен Node.js >= 18: `node --version`
2. Переустановите зависимости: `rm -rf node_modules && npm install`
3. Проверьте, не занят ли порт 3000: `lsof -i :3000`

### Android приложение не компилируется

**Решение:**
1. Очистите кэш: `./gradlew clean`
2. Пересоберите проект: `./gradlew build`
3. Синхронизируйте Gradle в Android Studio

## Архитектура

```
Android App  →  HTTP/REST  →  Node.js Proxy  →  stdio  →  MCP Server
   (Ktor)                      (Express.js)              (Filesystem)
```

Прокси необходим, потому что:
- MCP использует stdio (стандартный ввод/вывод)
- Android не может работать со stdio напрямую
- Прокси транслирует HTTP запросы в stdio команды
